# Sokrates-Teich

## Was ist es?

Sokrates’ Teich ist eine Webseite für Kinder mit selektivem Mutismus und Erwachsene in ihrem Umfeld. Sie bietet unter anderem Informationen, Spiele und Möglichkeiten zur Kommunikation ohne Worte. Sie ersetzt keine Therapie. Siehe [README](README.md).
